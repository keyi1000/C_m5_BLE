# M5Stack BLE暗号化通信プロジェクト

M5Stack CoreS3を使用したBLE通信とRSA暗号化/復号化を実装したプロジェクト

## 概要

M5Stack CoreS3デバイスをBLEサーバーとして動作させ、受信したRSA暗号化データを復号化して表示する

## 研究背景
BLEの自動接続と暗号通信に興味をもったため

## 研究目的
BLEの自動接続、通信の暗号化について知識を得てどのようなものか理解をする

## 主な機能

- **BLE通信**: BLEサーバーとして動作し、クライアントからの接続を待ち受け
- **自動再接続**: 接続が切断された場合、自動的にアドバタイジングを再開
- **RSA復号化**: RSA秘密鍵を使用して暗号化されたデータを復号化
- **リアルタイム表示**: 受信・復号化されたメッセージをM5Stackの画面に表示
- **接続ステータス管理**: 接続状態と接続回数をリアルタイムで追跡

## システム構成

- **ハードウェア**: M5Stack CoreS3
- **開発環境**: PlatformIO
- **フレームワーク**: Arduino
- **プラットフォーム**: ESP32 (espressif32)
- **主要ライブラリ**:
  - M5Unified (v0.2.10以上)
  - BLE Device (ESP32標準)
  - mbedTLS (RSA暗号化ライブラリ)
  - LittleFS (ファイルシステム)

## セットアップ

### 1. 必要なもの

- M5Stack CoreS3デバイス
- PlatformIO環境
- RSA秘密鍵ファイル (`private.pem`)

### 2. 秘密鍵の配置

`private.pem`ファイルをプロジェクトルートまたはデータディレクトリに配置してください。

### 3. ビルドとアップロード

```bash
# ビルド
pio run

# デバイスにアップロード
pio run --target upload

# シリアルモニタを開く
pio device monitor
```

## BLE仕様

- **サービスUUID**: `4fafc201-1fb5-459e-8fcc-c5c9c331914b`
- **キャラクタリスティックUUID**: `beb5483e-36e1-4688-b7f5-ea07361b26a8`
- **デバイス名**: `M5Stack BLE`
- **通信方式**: WRITE + NOTIFY対応

## 使用方法

1. M5Stack CoreS3にプログラムをアップロード
2. デバイスが起動すると自動的にBLEアドバタイジングを開始
3. BLEクライアント(スマートフォンアプリなど)から接続
4. 指定のキャラクタリスティックにRSA暗号化されたデータを送信
5. M5Stackの画面に復号化されたメッセージが表示される

## 画面表示

- **Status**: 接続状態 (Advertising / Connected)
- **Info**: 接続回数やメッセージ番号
- **Data**: 復号化されたメッセージ内容

## トラブルシューティング

- **接続できない**: デバイスを再起動してアドバタイジングを再開
- **復号化エラー**: 秘密鍵が正しく配置されているか確認
- **メッセージが表示されない**: シリアルモニタでエラーログを確認

## 研究結果
BLEの自動接続はとても単純でありセントラルとペリフェラルのUUIDが一致すれば接続されるものだった。
BLEの暗号化についても暗号通信に特化しているわけではなく、自ら平文→暗号文というようにこちらも単純なものであった。しかしBLE自体の仕様、キャラクタスティックの存在が難しく、一般的な通信よりも設計が求められると感じた。
